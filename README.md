# PDF書き込み君

ブラウザだけでPDFに文字を書き込み、別名でPDFファイルを保存するシンプルなアプリです。

## 使う

- **[アプリを開く](https://ken-tak-steam.github.io/pdf_kakikomikun/)**
- **[ダウンロード（確認画面）](https://ken-tak-steam.github.io/pdf_kakikomikun/download.html)**

ダウンロード後はHTML単体でオフライン動作。PDFファイルを外部送信しません。CDN読み込みもありません。

## 機能

- PDFの複数ページ表示、書き込み位置の指定、入力・移動・削除
- 日本語：ゴシック／明朝、英語：Arial／Times New Roman／Courier Newからフォント選択
- 文字サイズ・文字色変更
- **保存ファイル名を変更してPDFをダウンロード**（元のPDFを上書きしません）
- iPad・Mac・Windowsで使うことを想定したブラウザアプリ

## 留意事項

- 元のPDF全体を画像化せず、**追加したテキストだけを画像として重ねて保存**します。追加した文字そのものは検索・選択できません。
- フォントは実行端末にインストールされているものを利用するため、端末によって字体が異なる場合があります。英語フォントを選んでも、日本語入力部分は端末の代替フォントになる場合があります。
- 暗号化・パスワード付きPDF、一部の複雑なPDFは正しく編集・保存できない場合があります。保存したPDFを必ず確認してください。
- Safari等ではダウンロード保存先をブラウザや端末が決定します。画面の保存用リンクからダウンロードしてください。
- アプリの動作・実機互換性はすべての端末で検証されていません。
