# PDF書き込み君

PDFにテキストを書き込み、PDFとして保存できる、完全オフラインのHTMLアプリです。

## 利用方法

1. [ダウンロード確認ページ](https://ken-tak-steam.github.io/pdf_kakikomikun/) を開き、「確認してダウンロード」をクリックします。
2. ダウンロードした `PDF_kakikomikun.html` をSafari・Chrome等で開きます。
3. PDFを読み込み、文字を追加し、「PDFを保存」をクリックします。

**HTMLを開くだけではダウンロードは始まりません。** ダウンロード操作とブラウザの確認後に開始します。

## 特徴

- 単一HTML、外部CDN通信なし、ログイン不要、PDFの外部送信なし
- PDFを複数ページ表示し、テキストを入力・移動・文字サイズ・色変更
- PDFを別名で保存（元のPDFは画像化しない）
- iPadのSafari、Mac、Windowsのブラウザで利用可能な構成
- ドラッグ＆ドロップ対応

## 注意

- 追加した文字はPDF内の**画像**として埋め込まれます。追加した文字自体の文字検索や文字選択はできません。
- 元のPDF内のテキスト・ハイパーリンクは画像化せず維持する方式です。ただしPDFの種類や機能によっては維持できない場合があります。
- 暗号化・パスワード保護されたPDFには対応しません。
- フォーム、電子署名、特殊な回転ページ、複雑なPDFでは表示・保存結果が異なる場合があります。保存後は必ず内容をご確認ください。
